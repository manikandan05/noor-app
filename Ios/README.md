# Islamic Calendar & Daily Wisdom (SwiftUI, iOS 17+)
1. Xcode → New Project → iOS App "IslamicCalendarApp" (SwiftUI). Delete the generated App/ContentView files.
2. Drag `Sources/*.swift` and `Sources/Resources/*.json` into the target (tick "Copy items", add to target).
3. Add `Tests/CalendarTests.swift` to a unit-test target.
Content is draft: lessons are original reflections (no religious quotes); add verified references to lessons.json before publishing.

Add `Sources/Resources/translations.json` too. Arabic text is machine-translated and flagged in-app until a human reviewer approves it. Replace `SourcesPolicyView.contactEmail` before release.
